# Midnight PlatForm

A Minecraft mod that adds an eerie subway station dimension to your game.

## Overview

**Midnight PlatForm** is a horror-themed dimension mod for Minecraft. Step into a deserted subway station that shouldn't exist — and try to find your way back.

Two versions are available:

| Version | Minecraft | Loader |
|---|---|---|
| 1.20.1 | 1.20.1 | Forge |
| 1.21.1 | 1.21.1 | NeoForge |

No configuration required. Install the mod and enter the dimension to begin.

## Features

- A new horror dimension: the Midnight Station
- Atmospheric lighting, sound, and environment design
- Unique exploration and survival experience
- Lightweight and easy to install

Content may expand over time. Check release notes for updates.

## Installation

1. Install the correct version of **Minecraft** (1.20.1 or 1.21.1).
2. Install the matching loader: **Forge** for 1.20.1, or **NeoForge** for 1.21.1.
3. Download the matching mod file from the <Releases> page or Modrinth.
4. Put the `.jar` file into your `mods` folder.
5. Launch Minecraft and enjoy.
